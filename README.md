## Note
This repo is just the deploy repo used for github page of npython playground, \
  a.k.a. just a placeholder for continuous-deploy(CD), \
  serving as a online demo.

## Why A Placeholder Repo?
Because github only allows one github-page per repo, and the homepage of origin repo([npython][nimpylib/npython]) is used to deploy document, \
another repo (like this repo) is required to deploy another github-page.
